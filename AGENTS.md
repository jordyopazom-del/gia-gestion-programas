# Reglas de Comportamiento del Asistente (GIA-CESFAM)
1. **Estricto apego a la solicitud**: Implementar única y exclusivamente lo que el usuario pide. No hacer rediseños no solicitados.
2. **No eliminar funciones**: No borrar submódulos, pestañas o funcionalidades que ya estaban funcionando y aprobadas, a menos que el usuario lo indique explícitamente.
3. **Validar antes de innovar**: Si hay una idea de mejora sustancial (como unificar vistas o cambiar flujos), consultar primero con el usuario antes de aplicarla en el código.
